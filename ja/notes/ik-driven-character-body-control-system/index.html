IK-driven Character Body Control System

IK-driven Character Body Control System は、従来の入力デバイス（キーボード＆マウス、ゲームパッド）と 6DoF VR モーションコントローラーとの間にある操作体験の溝を埋めるために設計された、実験的な一人称／三人称（FPP/TPP）向けキャラクター操作システムです。プレイヤーの手動操作による直感的な 3D 空間リーチ・奥行き・掌の向きの制御を提供し、プロシージャルな全身逆運動学（Procedural Full-Body IK / VRIK）によって上半身の姿勢・脊椎のしなり・胴体の傾きを自動連動させることで、自然で説得力のある物理インタラクションを実現します。

着想と設計思想#

従来の非 VR ゲームにおける環境インタラクションは、大半が二者択一的です。キーを押して定型のアニメーション（Canned Animation）を再生させるか、クロスヘアによるレイキャストで剛体オブジェクトを操作するにとどまります。対照的に、6DoF VR システムは圧倒的な物理的能動性（Physical Agency）と没入感をもたらし、プレイヤーが自らの手を 3D 空間へ伸ばし、触れ、位置を合わせ、引き寄せるといった直接的な挙動を可能にします。

本プロジェクトは、操作体系を過度に複雑化させることなく、同等の空間操作感をいかにして通常ディスプレイ（フラットスクリーン）へ落とし込めるかという探求から始まりました。その設計は、OPERATOR におけるドアノブを直接押し開けるような物理インタラクションをはじめ、VRChat や Arma Reforger がもたらす一人称視点での身体性やフリールック（Free Look）、そして TABG や How to Fish に見られる動的な四肢の触感フィードバックなど、数々の作品から受けたインスピレーションによって形作られています。

本システムでは、キャラクターの手足を不器用なラグドールのように操るのではなく、「プレイヤーによる能動的入力」 と 「プロシージャルな受動的補正」 の役割を明確に切り分けています：

  • 能動的操作（プレイヤー入力）：プレイヤーは空間的な意図を直接指示します。左右の手の個別展開、ホイールによるリーチ深度の調整、掌のピッチ／ロール回転、ピンチ入力によるドラッグなどを担当します。
  • 受動的補正（プロシージャル IK）：脊椎の湾曲、胴体の捻り、肩の前方突出、肘の曲がりヒント（Elbow Hints）などは、解剖学的に自然な姿勢を保つよう、全身 IK ソルバーがリアルタイムにプロシージャル解算を行います。

システムアーキテクチャ#

本アーキテクチャは、純粋な空間幾何計算およびステート管理ロジックを、Unity エンジンのライフサイクルや特定のアニメーションリグから疎結合に分離しています。

1. 純粋ステートマシンと意図パイプライン#

基礎レイヤーにおいて、HandStateController が左右の手の独立した実行状態（Resting 静止、FreeReaching 自由伸展、Retracting 格納、AttachedOpen 吸着・開手、AttachedPinched 吸着・ピンチ）を管理します：

  • 深度同期を備えた独立トグル：左右の手を個別に展開・格納できます。両手を同時に前進させた場合は、伸展深度が自動的かつ滑らかに同期します。
  • サーフェスおよびハンドルへの吸着（SliderHandleInteractionTarget）：OPERATOR などの扉操作メカニクスに着想を得ており、インタラクト可能なオブジェクト付近へ手を伸ばすと、事前定義された接触アンカーへ自動吸着します。ピンチ／ドラッグ入力を保持することで、視線ピッチの差分やホイール入力を対象オブジェクトの移動軸（ドアハンドルの押し込みやラッチのスライドなど）へダイレクトに反映し、開手・ピンチ・離脱で異なる掌ポーズを描画します。

2. 解析的空間リーチソルバー#

HandReachSolver は、Unity のコンポーネントに依存しない純粋な C# 数学ソルバーであり、ボーン変形が適用される前に目標となる掌の姿勢（Transform）を算出します：

  • 収束型リーチ軌道（Converging Reach Path）：腕を前に伸ばす軌道は、単に平行に押し出されるわけではありません。近距離では肩幅に合わせた広い間隔を保ち、遠方へ伸ばすにつれて中心へ向かって直線的に収束（Converge）していくことで、人間の両腕の自然な解剖学的伸展を忠実に再現します。
  • 掌の姿勢フレーム：中立フレームを基準とした符号付きピッチ角と左右対称のインワードロール（内転）角から回転を生成し、どのようなリーチ高度にあっても手首の向きが破綻しないよう制御します。

3. VRIK 駆動とポスチャシェイピング#

算出された抽象的な手先ターゲットを RootMotion の VRIK へ橋渡しする処理は HandPoseDriver が担当し、IK の更新前後（OnPreUpdate および OnPostUpdate）へ直接フックします：

  • 胴体の回転意図と胸部ターゲット（Torso Intent & Chest Goal）：前方へのリーチや身体の中心線を横切る動作で腕が不自然に伸びきってしまうのを防ぐため、解剖学的な制限範囲内で胴体のヨー角意図を算出し、VRIK の胸部ゴール（Chest Goal）を自然に前傾・回旋させます。
  • 動的エルボーヒント（Dynamic Elbow Hints）：肩の位置と腕の伸び具合から曲がり目標点（Bend Goal）をリアルタイムに計算します。リーチの深さやブレンド率に応じて、肘が自然に下がり、または外側へ広がるよう制御されます。
  • 指先ポーズのオーバーレイ（Finger Posture Overlays）：インタラクション中や離脱時に、プロシージャルな指先姿勢が基本アニメーションクリップの上へ滑らかに重ね合わされます。

4. 視線分離フリールックとトゥルー一人称#

一人称視点において、視界を振った際に腕全体が不自然に引きずられてしまう挙動は、没入感を大きく損なう要因となります：

  • フリールックとリーチ座標系の分離（Free-Look Reach Decoupling）：手先の空間リーチ座標系をワールド空間に固定したまま、視線のみを自由に回転させることができます。顔を横に向けた状態でも、両手は作業面や吸着対象の上へ安定して留まり続けます。
  • トゥルー一人称のカリング制御（True First-Person Mesh Culling）：FirstPersonPartCuller を通じて、一人称カメラからキャラクターのアバターの頭部・顔面メッシュのみを非表示にし、胴体・両腕・両脚、および地面への投射影（ShadowsOnly）を完全に維持します。

まとめと現状#

本プロトタイプは、プロシージャルな全身 IK が解剖学的な妥当性を下支えすることで、一般的なキーボード・マウスやゲームパッドであっても、三次元空間での手動インタラクションが極めて高い応答性と物理的な手触り、そして説得力を獲得できることを示しています。従来の受動的・単調なキー操作を、表現力豊かな空間アクションへと昇華させる試みです。
