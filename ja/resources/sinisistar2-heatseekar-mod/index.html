SiNiSistar2 HeatSeekar Mod は、SiNiSistar2（DLsite / Steam）をより快適に遊ぶための無料 Mod です。マウスボタンの直接割り当て、マウスによるメニュー操作、画面設定の改善などに対応しています。

すぐに使いたい方はダウンロードへどうぞ。

はじめに#

ナメクジ仲間の皆さん、こんにちは。

SiNiSistar2 が Steam で発売され、私が Modernization Mod Pack を公開してから数か月が経ちました。その間、トリビュート同人ゲーム「ラビアン」や、いくつかの別のプロジェクトに取り組んでいました。今ご覧になっているこのサイトも、その一つです。

最近ふと、以前の Mod パックにあった便利な機能をゲーム標準のメニューに組み込む、新しい Mod を作ろうと思い立ちました。あわせて、以前の Mod で使っていたキー変換を介する方式に代えて、ゲームがマウスボタンの入力を直接扱えるようにしました。

私の Mod を使ってくださってありがとうございます。楽しんでいただけたらうれしいです！

ここに書いてよいのかわかりませんが、私の一番の願いは、SiNiSistar シリーズを制作する同人サークル Uu の皆さん、特にデザイナーのねんないさんに気づいてもらい、認めてもらうことです。

引き続き精進してまいります、ねんないさん！

機能#

> 今後、さらに便利な機能を追加するかもしれません。

グラフィック#

  • 解像度の改善：ゲーム本来のアスペクト比 2:1 を保ちながら、モニターに合った解像度を設定できます。

  • フルスクリーン表示の改善：拡大によるぼやけを抑え、UI を鮮明に表示できるようにします。

  • フレームレート制限の改善：フレームレートの上限を設定したり、制限を解除したりできます。

オーディオ#

  • バックグラウンド時のミュート切り替え：ゲームウィンドウからフォーカスが外れると、ゲームをミュートします。（Alt-Tab で切り替えたとき、裏で流れている Sistars の喘ぎ声を周りに聞かれないように！）

UI・操作性#

  • マウスへの直接対応：マウスボタンをゲーム内の操作に直接割り当て、マウスでメニューを操作できます。（そう、キーボードでもマウスでも、片手だけでギャラリーを閲覧できるようになりました。）

  • ポートレートおよび HUD の非表示機能：ポートレート非表示時は視界を広く保つため、HUD レイアウトもコンパクトモードに切り替わります。

  • 高解像度に設定すると Audio ページの音量の数値が表示されなくなる問題を修正します。

ゲームプレイ#

  • Exploding Arrow Magic の別の発動方法：Shoot Magic で狙いを定めている間に Attack を押すことで、Exploding Arrow Magic を発動できます。

  • キャラクターのマウス照準：マウスで攻撃方向や Shoot Magic の照準方向を操作できるチート機能です（使用は非推奨、初期設定では無効）。

インストール方法#

ゲームを終了してから、SiNiSistar2.exe があるフォルダーにパッケージを展開してください。確認が表示されたら、フォルダーを統合し、ファイルを上書きします。フルパッケージを導入した場合、関連ファイルの配置は次のようになります。

ゲームフォルダー/
├── SiNiSistar2.exe                # 既存のゲームファイル
├── SiNiSistar2_Data/              # 既存のゲームファイル
├── BepInEx/
│   ├── core/                      # BepInEx
│   └── plugins/
│       └── HeatSeekar/            # HeatSeekar（両パッケージ共通）
│           ├── SiNiSistar2.HeatSeekar.dll
│           ├── assets/            # カーソル・照準の PNG
│           └── localization/      # 翻訳 JSON ファイル
├── dotnet/                        # BepInEx
├── .doorstop_version              # BepInEx
├── changelog.txt                  # BepInEx
├── doorstop_config.ini            # BepInEx
└── winhttp.dll                    # BepInEx

Mod 単体パッケージも同じ BepInEx/plugins/HeatSeekar/ に配置します。互換性のある BepInEx 6 IL2CPP があらかじめインストールされている必要があります。

ゲームを起動し、標準の Settings と Graphics ページから HeatSeekar を設定してください。BepInEx 導入後の初回起動は、必要なファイルを準備するため時間がかかることがあります。

更新方法#

ゲームを終了し、新しいパッケージを同じゲームフォルダーに展開してください。確認が表示されたら、ファイルを上書きします。

更新パッケージには、標準の翻訳 JSON ファイルとカーソル・照準の PNG が含まれます。自分で編集したファイルは、上書きする前にバックアップしてください。互換性のある BepInEx が導入済みで、自分の編集内容を残したい場合は、BepInEx/plugins/HeatSeekar/SiNiSistar2.HeatSeekar.dll だけを更新することもできます。

カスタマイズ#

HeatSeekar のファイルは BepInEx/plugins/HeatSeekar/ に保存されます。

  • 翻訳：localization/<language>/ui.json を編集してください。変更はゲームの実行中に自動で再読み込みされます。英語、日本語、韓国語、簡体字中国語、繁体字中国語を同梱しています。ゲームに登録されているカスタム言語についても同名のフォルダーを作成し、内蔵の翻訳がない言語には英語のテンプレートを生成します。
  • カーソルと照準：assets/cursor.png と assets/crosshair.png を差し替えるか、HeatSeekar.cfg の [Cursor] と [Crosshair] セクションで ImagePath を指定してください。HotspotX と HotspotY の範囲は 0〜1 で、画像の左上を原点とします。0.5, 0.5 は中央です。これらの設定を変更したら、ゲームを再起動してください。

標準の翻訳ファイルや画像ファイルがない場合は、DLL に埋め込まれたリソースから自動生成されます。Mod の起動時には既存のファイルを保持しますが、更新パッケージを展開すると上書きされる場合があります。

ダウンロード#

現在のバージョン：HeatSeekar 0.8.3。Windows x64 向けです。SiNiSistar2 1.2.1 と 1.3.1 でテストしています。

0.8.3 更新内容： Aki menu navigation 有効時の Gallery 操作を改善しました。Q/E でページ切替、A/D で現在のページの項目選択、L でスロー、P で停止を操作できます。画面内のキー表示も対応する小文字に同期されます。戻る／キャンセル、最初の方向キー入力によるフォーカス、標準 Binding ページのナビゲーションも修正し、Aki menu navigation を無効にすると拡張キー割り当てと helper テキストが削除されます。

ダウンロード内容
最新リリースをダウンロード初めて導入する場合は BepInEx 同梱のフルパッケージ、互換性のある BepInEx 6 IL2CPP が導入済みの場合は Mod 単体パッケージを使用できます。

フルパッケージには、Unity IL2CPP / Windows x64 向けの BepInEx 6.0.0-be.754 が含まれています。

最新リリースには上記の両方のパッケージが含まれています。GitHub が自動で用意する Source code のダウンロードには、ソースファイルが入っています。

不具合の報告#

問題が発生した場合は、ゲームのバージョン、再現手順、BepInEx/LogOutput.log を添えて issue を作成してください。
