IK-driven Character Body Control System 是一套实验性的第一与第三人称角色交互系统，旨在弥合键盘、鼠标与手柄等传统输入设备与 6 自由度 VR 动作控制器之间的操作体验鸿沟。该系统为玩家的双手机动提供了直观的 3D 空间伸展、深度调节与手掌朝向控制，并通过程序化全身反向动力学自动协调上身姿态、脊椎曲度与躯干倾斜，以实现自然可信的物理交互。

灵感来源与设计哲学#

在传统的非 VR 游戏中，环境交互多为二元状态：玩家通过按下按键触发一段固定的预制动画，或是仅凭准星射线拾取刚体道具。与此相对，6 自由度 VR 设备赋予了玩家极高的物理能动性与沉浸感——允许玩家直接伸手探入 3D 空间，去触摸、校准对齐或拖拽物体。

本项目的初衷，正是探索如何将这种空间操作感引入传统的平面屏幕中，同时避免操作机制变得繁琐晦涩。整个系统的设计思路深受多款作品的启发：无论是 OPERATOR 中伸手推拉门把手的触觉反馈，VRChat 与 Arma Reforger 在第一人称视角下营造的身体临场感与自由视线，还是 TABG 与 How to Fish 等游戏中动态肢体带来的即兴物理反馈，都在这套交互框架中留下了印记。

系统并未将角色肢体做成笨拙的布娃娃木偶，而是严格划分了玩家主动控制与程序化被动代偿的职责边界：

  • 玩家主动控制：玩家直接输入空间交互意图——独立切换任一手、通过滚轮调节伸展深度、旋转手掌俯仰与内翻角度、或按住进行捏合拖拽。
  • 程序化被动代偿：角色的脊柱弯曲、躯干转动、肩膀前探与肘部弯曲提示，全部由全身 IK 解算器实时程序化解算，维持自然的人体解剖学姿态。

系统架构#

该架构将纯粹的空间数学与状态逻辑同 Unity 引擎生命周期及动画骨骼深度解耦。

1. 纯状态机与意图管线#

在基础层，HandStateController 负责管理双手的独立运行状态，涵盖静止、自由伸展、缩回、吸附张开与吸附捏紧：

  • 独立开关与共享深度：左右手可分别独立唤出或收回。当双手同时向前伸展时，伸展深度会自动平滑同步。
  • 表面与把手吸附：直接受到 OPERATOR 等游戏中物理化开门机制的启发，当手掌接近可交互物件时，会自动吸附至预设的接触锚点。按住捏合/拖拽键即可将视角俯仰差值或滚轮输入转换为目标物体的物理位移（例如推压门把手或推拉滑栓），并在张开、捏紧与释放时呈现差异化的手掌姿态。

2. 解析空间伸展解算器#

HandReachSolver 是一个不依赖 Unity 引擎组件的纯 C# 数学解算器，在骨骼变换计算前求出目标手掌位姿：

  • 聚拢式伸展轨迹：手臂向前伸展并非沿两条平行的直线推进。解算器在近距离时采用较宽的肩宽间距，随着向前延伸线性插值收敛到较窄的间距，完美拟合人体双臂自然伸展的几何学。
  • 手掌朝向框架：手掌旋转由相对于中性参考系的俯仰角与对称内翻角计算得出，确保手腕在任意伸展高度下都能维持合理的空间朝向。

3. VRIK 姿态驱动与形态塑造#

HandPoseDriver 负责将抽象的手部解算目标桥接到 RootMotion 的 VRIK 中，直接接入解算前后管线的 OnPreUpdate 与 OnPostUpdate 阶段：

  • 躯干意图与胸腔目标：为避免向前伸展或跨越身体中心线时手臂过度拉伸，驱动器会解算一个被限制在解剖学范围内的躯干偏航意图，引导 VRIK 胸腔目标自然前倾扭转。
  • 动态手肘提示：根据肩膀位置与手臂伸展幅度实时生成弯曲目标点。肘部会根据伸展深度和混合权重呈现出自然的下沉或外展弧度。
  • 手指姿态叠加：在交互与释放过程中，程序化手指姿态会平滑覆盖在基础动画剪辑之上。

4. 解耦自由视线与真第一人称#

在第一人称游戏中，如果一转动视角就强行扯动整个手臂，代入感往往会被瞬间打破：

  • 自由视线与伸展解耦：玩家可以自如环顾四周，同时将手部的空间伸展坐标系冻结在世界空间中。即使头部扭向一侧，双手依然能专注稳定地停留在当前作业平面或吸附物体上。
  • 真第一人称网格裁剪：通过 FirstPersonPartCuller，在第一人称相机下隐藏角色的头部与面部模型，同时完整保留躯干、双臂、双腿以及在地面上的物理投射阴影。

核心总结与当前状态#

该原型系统验证了：只要利用程序化 IK 做好全身解剖学姿态的自然代偿，即使在标准键鼠和手柄上，三维空间的双手手动交互同样能够兼具灵敏度、物理触感与真实可信度，将原先单调被动的交互按键升华为富有表现力的空间操作机制。
