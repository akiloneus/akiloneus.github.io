SiNiSistar2 HeatSeekar Mod 是一款面向 SiNiSistar2（DLsite / Steam）的免费游戏体验优化 Mod，提供原生鼠标按键绑定、菜单鼠标操作、显示选项改进等功能……

太长不看，直接前往下载。

前言#

各位蛞蝓，大家好。

距离 SiNiSistar2 在 Steam 上发售，以及我上传 Modernization Mod Pack，已经过去几个月了。这段时间我一直在开发致敬同人游戏 Rabiane，也在做其他几个项目——包括你现在正在浏览的这个网站。

直到最近，我突然有了一个想法：做一个新 Mod，把旧 Mod 包里的实用功能整合进游戏的原生菜单，同时让游戏直接支持鼠标按键输入，替代之前通过按键映射实现的方式。

感谢你使用我的 Mod，希望你玩得开心！

不知道在这里说是否合适，不过我最大的心愿，是能得到 SiNiSistar 系列的制作社团 Uu，尤其是设计师 Nennai 的关注和认可。

引き続き精進してまいります、ねんないさん！

功能#

> 今后可能会加入更多改善游戏体验的功能。

图形#

  • 分辨率改进：在保留游戏原有 2:1 画面比例的同时，可以选择更适合显示器的分辨率。

  • 全屏模式改进：改善全屏显示方式，让界面元素保持清晰，不再因放大而模糊。

  • 帧率限制改进：可以设置帧率上限，也可以解除帧率限制。

音频#

  • 后台静音开关：游戏窗口失去焦点时自动静音。（Alt-Tab 切出去时，别让别人听到 Sistars 在后台的呻吟声！）

界面与操作#

  • 原生鼠标支持：将鼠标按键直接绑定到游戏操作，并用鼠标操作菜单。（没错，现在只用一只手就能浏览画廊，无论是用键盘还是鼠标。）

  • 隐藏立绘及 HUD 功能：隐藏立绘时 HUD 布局也会切换为紧凑模式，让画面视野更清晰。

  • 修复了较高分辨率下 Audio 页面不显示音量数值的问题。

玩法#

  • Exploding Arrow Magic 的另一种触发方式：在使用 Shoot Magic 瞄准时按下 Attack，即可触发 Exploding Arrow Magic。

  • 角色鼠标瞄准：一项作弊功能（不推荐使用，默认关闭），可以用鼠标控制角色的攻击方向和 Shoot Magic 的瞄准方向。

安装方法#

关闭游戏，将安装包解压到 SiNiSistar2.exe 所在的文件夹，并在出现提示时合并文件夹、替换文件。安装完整包后，相关文件的目录结构应如下所示：

游戏文件夹/
├── SiNiSistar2.exe                # 游戏原有文件
├── SiNiSistar2_Data/              # 游戏原有文件
├── BepInEx/
│   ├── core/                      # BepInEx
│   └── plugins/
│       └── HeatSeekar/            # HeatSeekar（两种包均包含）
│           ├── SiNiSistar2.HeatSeekar.dll
│           ├── assets/            # 鼠标指针和准星 PNG
│           └── localization/      # 翻译 JSON 文件
├── dotnet/                        # BepInEx
├── .doorstop_version              # BepInEx
├── changelog.txt                  # BepInEx
├── doorstop_config.ini            # BepInEx
└── winhttp.dll                    # BepInEx

纯 Mod 包也使用 BepInEx/plugins/HeatSeekar/ 这个路径，需要事先安装兼容的 BepInEx 6 IL2CPP。

启动游戏后，可以在游戏原生的 Settings 和 Graphics 页面中调整 HeatSeekar 的设置。首次使用 BepInEx 启动时，需要准备相关文件，可能会花费较长时间。

更新方法#

关闭游戏，将新版安装包解压到同一个游戏文件夹，并在出现提示时替换文件。

更新包包含默认的翻译 JSON 文件和鼠标指针／准星 PNG。如果修改过这些文件，请先备份再覆盖。如果想保留自定义文件，且已经安装了兼容的 BepInEx，也可以只更新 BepInEx/plugins/HeatSeekar/SiNiSistar2.HeatSeekar.dll。

自定义#

HeatSeekar 的文件存放在 BepInEx/plugins/HeatSeekar/ 下。

  • 翻译：编辑 localization/<language>/ui.json，修改会在游戏运行时自动重新加载。内置英语、日语、韩语、简体中文和繁体中文。对于游戏已注册的自定义语言，HeatSeekar 也会创建同名文件夹；没有内置翻译的语言会以英文内容作为初始模板。
  • 鼠标指针和准星：替换 assets/cursor.png 和 assets/crosshair.png，或在 HeatSeekar.cfg 的 [Cursor] 和 [Crosshair] 部分设置 ImagePath。HotspotX 和 HotspotY 的取值范围是 0 到 1，以图片左上角为原点；0.5, 0.5 表示中心。修改这些配置项后，请重启游戏。

缺失的默认翻译和图片文件会从 DLL 的内嵌资源中自动生成。Mod 启动时会保留已有文件，但安装更新包时仍可能覆盖它们。

下载#

当前版本：HeatSeekar 0.8.3，适用于 Windows x64。已在 SiNiSistar2 1.2.1 和 1.3.1 中测试。

0.8.3 更新： 改进开启 Aki menu navigation 后的 Gallery 导航。使用 Q/E 切换页面，A/D 选择当前页按钮，L 控制慢速播放，P 控制停止。界面按键提示已同步为对应的小写字母。返回／取消、首次方向键聚焦和原生 Binding 页面导航也已恢复；关闭 Aki menu navigation 后会移除增强绑定和 helper 文字。
