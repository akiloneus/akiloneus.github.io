SiNiSistar2 HeatSeekar Mod is a free quality-of-life mod for SiNiSistar2 (DLsite/Steam) with native mouse bindings, mouse support for menus, improved display options and more...

TL;DR, take me to Download.

Intro#

Greetings, fellow slugs.

It's been a couple of months since SiNiSistar2 launched on Steam and I uploaded the Modernization Mod Pack. I have been working on the tribute doujin game Rabiane and several other projects—which also include the website you are reading on right now.

Not until recently, I had this idea all of a sudden, to make a new mod that implements those useful functions in the mod pack into the game's native menu, and makes the game support mouse key input natively, to replace the key mapping workaround method of my previous mod.

Thank you for using my mod. Hope you enjoy it!

I am not sure if this is the place to say it, but my biggest wish is to get noticed and recognized by Uu, the doujin circle behind the SiNiSistar series, especially its designer, Nennai.

Features#

> More QoL functions may be added in the future.

Graphics#

  • Improved resolution: Allows you to set a resolution that fits your monitor better while preseving the game's original 2:1 aspect ratio.

  • Improved fullscreen mode: A better implementation of fullscreen display mode that is able to keep the UI elements sharp clear (no more blurry upscaling).

  • Improved framerate limiter: Allows you set a framerate cap or set the framerate unlimited.

Audio#

  • Mute in background toggle: The function that mutes the game window when it is not focused. （Don't let others hear Sistars' moaning in the background when you alt-tab out!）

UI/UX#

  • Native mouse support: Bind mouse buttons directly to in-game actions and navigate menus with the mouse. (Yes, you can now navigate the gallery with a single hand, using a keyboard or mouse.)

  • Fixes an issue where the volume value in Audio page would not show when higher resolution is set.

Gameplay#

  • Exploding Arrow alt trigger: An alternate key combination for triggering Exploding Arrow Magic (Shoot Magic aiming + Attack).

  • Character mouse aiming: A CHEAT function (not recommended, disabled by default) allows you to control attack direction and aiming direction of Shoot Magic.

How to install#

Close the game, then extract the package into the folder containing SiNiSistar2.exe, merging folders and replacing files when prompted. After installing the full package, the relevant files should look like this:

Game folder/
├── SiNiSistar2.exe                # Existing game file
├── SiNiSistar2_Data/              # Existing game files
├── BepInEx/
│   ├── core/                      # BepInEx
│   └── plugins/
│       └── HeatSeekar/            # HeatSeekar (both packages)
│           ├── SiNiSistar2.HeatSeekar.dll
│           ├── assets/            # Cursor and crosshair PNGs
│           └── localization/      # Translation JSON files
├── dotnet/                        # BepInEx
├── .doorstop_version              # BepInEx
├── changelog.txt                  # BepInEx
├── doorstop_config.ini            # BepInEx
└── winhttp.dll                    # BepInEx

The mod-only package uses the same BepInEx/plugins/HeatSeekar/ location and requires a compatible BepInEx 6 IL2CPP installation.

Start the game and configure HeatSeekar through the native Settings and Graphics pages. The first launch with BepInEx may take longer while it prepares its files.

Updating#

Close the game and extract the new package into the same game folder, replacing files when prompted.

Updates include the default translation JSON files and cursor/crosshair PNGs. Back up any customized files before replacing them. If you want to retain your custom files, you can update only BepInEx/plugins/HeatSeekar/SiNiSistar2.HeatSeekar.dll when your BepInEx installation is already compatible.

Customization#

HeatSeekar stores its files under BepInEx/plugins/HeatSeekar/.

  • Translations: Edit localization/<language>/ui.json. Changes reload while the game is running. English, Japanese, Korean, Simplified Chinese, and Traditional Chinese are included. HeatSeekar also creates matching folders for custom languages registered by the game; languages without a built-in translation start with English.
  • Cursor and crosshair: Replace assets/cursor.png and assets/crosshair.png, or set ImagePath in the [Cursor] and [Crosshair] sections of HeatSeekar.cfg. HotspotX and HotspotY range from 0 to 1, measured from the image's top-left corner; 0.5, 0.5 is the center. Restart the game after changing these configuration settings.

Missing default translation and image files are generated from the DLL's embedded resources. Existing files are preserved when the mod starts. Installing an update package can still replace them.

Download#

Current release: HeatSeekar 0.8.1 for Windows x64. Tested with SiNiSistar2 1.2.1 and 1.3.1.

0.8.1 update: Fixes menu text being covered by black bars with Preserve 2:1, while keeping the game world and HUD within 2:1. A more compact help area gives Video enough room to show all options without scrolling. The HeatSeekar page now uses the standard back controls instead of a separate Back button.
